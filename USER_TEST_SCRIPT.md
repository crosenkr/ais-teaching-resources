# AIS Teaching Resources — User Test Script

**Purpose:** Evaluate the usability and usefulness of the AIS Teaching Resources prototype.
**Time required:** ~15 minutes
**How to test:** Open the website link provided. Use your normal browser (desktop or mobile).

---

## Part 1: First Impressions (2 min)

1. Open the website. Without clicking anything, answer:
   - What is this website for?
   - Who is the target audience?
   - What types of resources would you expect to find here?
   - Does the design feel consistent with AIS branding?

---

## Part 2: Task-Based Testing (8 min)

Complete the following tasks. Note any difficulties or confusion.

### Task 1: Browse by category
- Find the **Vendor Academic Programs** category
- How many resources are in this category?
- Find the SAP University Alliances entry. Is the description helpful?

### Task 2: Search for a topic
- Use the search bar to find resources related to **"cybersecurity"**
- How many results appear?
- Are the highlighted search terms helpful for scanning results?

### Task 3: Filter by tag
- Click the **"ERP"** tag on any resource card
- What happens? Is the behavior what you expected?
- How do you clear the tag filter?

### Task 4: Combine filters
- Select the **"Simulations & Experiential Learning"** category
- Then search for **"SAP"** within that category
- Can you find ERPsim? Is the description adequate?

### Task 5: Find a regional resource
- Find resources for the **German-speaking IS community**
- Can you find the WKWI curriculum recommendation?
- Is the "Regional & Language-Specific IS Communities" category name clear?

### Task 6: Share a filtered view
- Filter resources to show only **"AI & GenAI in Education"**
- Copy the URL from your browser's address bar
- Open it in a new tab — does the same filtered view appear?

### Task 7 (mobile only): Use the category filter
- On your phone, can you find and use the category dropdown?
- Is the layout readable on your screen?

---

## Part 3: Content Review (3 min)

1. Are there important IS teaching resources **missing** from this collection? Please list any you know of.
2. Are any listed resources **outdated, broken, or irrelevant**?
3. Are the **16 categories** intuitive? Would you merge, rename, or add any?
4. Are the **tags** on resources useful for finding what you need?
